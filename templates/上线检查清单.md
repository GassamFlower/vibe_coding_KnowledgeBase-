# 上线检查清单

> **用法**：进入上线门时逐项检查，结果写入项目 `docs/p-上线前验收报告.md`。
> 每项必须有证据；没有实际执行的项目标记为“未验证”。

---

## 1. 上线前

- [ ] 删除本地构建缓存后重新构建通过；
- [ ] 构建命令、输出目录、运行命令已记录；
- [ ] 生产环境变量清单完整；
- [ ] `.env.example` 与实际变量一致；
- [ ] 密钥没有进入代码仓库；
- [ ] 数据库迁移可以在生产执行；
- [ ] 数据库已备份；
- [ ] 依赖漏洞检查完成，高危漏洞已处理；
- [ ] 冒烟测试清单已准备；
- [ ] 回滚方案和上一版产物已准备；
- [ ] 变更记录已更新。

---

## 2. 部署

- [ ] 部署使用正式分支或正式构建产物；
- [ ] 构建日志无错误；
- [ ] 生产配置与开发配置已区分；
- [ ] 生产环境没有开启调试模式；
- [ ] 数据库迁移已执行并验证；
- [ ] 静态资源、接口、后台任务都已启动；
- [ ] 定时任务和队列消费者已启动（如适用）。

---

## 3. 域名与 HTTPS

- [ ] 域名解析已生效；
- [ ] 正式地址可以访问；
- [ ] HTTPS 证书有效；
- [ ] HTTP 会跳转到 HTTPS；
- [ ] 证书自动续期已验证；
- [ ] Cookie 域名和安全属性正确；
- [ ] 备案信息已确认（如适用）。

---

## 4. 生产冒烟测试

- [ ] 首页可以打开；
- [ ] 登录、退出、会话保持正常；
- [ ] 核心读取功能正常；
- [ ] 核心写入功能正常，数据真的写入；
- [ ] 支付、回调、退款等关键链路正常（如适用）；
- [ ] 文件上传和下载正常（如适用）；
- [ ] 404 和错误页面正常；
- [ ] 手机网络可以访问；
- [ ] 日志中能看到本次请求；
- [ ] 监控面板显示在线。

---

## 5. 日志与监控

- [ ] 应用日志包含请求标识、错误码、关键业务动作；
- [ ] 日志不记录密码、令牌、完整身份证号、支付信息；
- [ ] 可用性监控已配置；
- [ ] 错误率、响应时间、数据库连接数有监控；
- [ ] 告警阈值和接收人已配置；
- [ ] 日志保留时间符合需要。

---

## 6. 回滚

- [ ] 上一版构建产物或镜像已保留；
- [ ] 回滚命令已记录；
- [ ] 数据库迁移的回退或恢复步骤已记录；
- [ ] 不可逆迁移已有备份；
- [ ] 功能开关或灰度方案已准备（如适用）；
- [ ] 回滚演练已完成。

---

## 7. SEO 与分享

- [ ] title 和 description 唯一且具体；
- [ ] canonical 正确；
- [ ] `sitemap.xml` 可以访问；
- [ ] `robots.txt` 配置正确；
- [ ] Open Graph 标题、描述、图片、地址完整；
- [ ] 分享卡片预览正常；
- [ ] 404 和 301 跳转正确；
- [ ] 页面在手机宽度下正常。

---

## 8. 统计

- [ ] 只接入一个主统计工具；
- [ ] 页面访问和关键事件可以上报；
- [ ] 事件命名已记录；
- [ ] 核心指标有基线；
- [ ] 不在 URL 和事件参数中放敏感信息；
- [ ] 需要 Cookie 同意时已配置。

---

## 9. 合规

- [ ] 隐私政策可以打开；
- [ ] 用户协议可以打开；
- [ ] Cookie 说明可以打开（如适用）；
- [ ] 退款、订阅、自动续费规则已说明（如适用）；
- [ ] 联系方式和服务主体信息完整；
- [ ] 备案信息已展示（如适用）。

---

## 10. 上线后观察

### 24 小时

- [ ] 错误率没有明显上升；
- [ ] 核心接口响应时间正常；
- [ ] 没有持续告警；
- [ ] 用户反馈渠道可用；
- [ ] 发现的问题已记录。

### 7 天

- [ ] 核心指标有第一轮数据；
- [ ] 反馈已分类；
- [ ] 严重问题已修复或登记；
- [ ] 迭代计划已更新。

### 30 天

- [ ] 完成阶段复盘；
- [ ] 指标与基线对比；
- [ ] 决定继续、调整或停止；
- [ ] 经验已反哺到 Skill 库。

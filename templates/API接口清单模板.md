## 4. 错误码表

| 错误码 | 状态码 | 含义 | 触发条件 | 处理建议 |
|---|---|---|---|---|
| `VALIDATION_ERROR` | 400 | 参数校验失败 | | 修正入参 |
| `UNAUTHORIZED` | 401 | 未登录或会话失效 | | 重新登录 |
| `FORBIDDEN` | 403 | 无权限 | | 联系管理员 |
| `NOT_FOUND` | 404 | 资源不存在 | | 检查标识 |
| `CONFLICT` | 409 | 重复提交或状态冲突 | | 刷新后重试 |
| `RATE_LIMITED` | 429 | 请求过于频繁 | | 稍后重试 |

## 三、使用规则

1. 先按阶段定位；章节与门禁的对应在工程手册索引，入门篇与进阶篇的章节内容在各自索引，专题观点在文章索引，项目复盘在案例索引，界面取料在 UIUX 参考库索引。
2. 同一内容只在一处写完整：章节对照、章节摘要、文章摘要、案例复盘、界面规范各自成文，其他文件只放链接。
3. 原文改名或移动时，更新对应索引的链接与摘要，不整段复制正文。
4. 外部方法与知识库门禁卡冲突时，以门禁卡为准，并在复盘记录里写明差异。

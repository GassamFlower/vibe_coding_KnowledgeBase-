# 架构门自动验收

> 基于 `../../templates/门禁卡-架构门.md` 转化的可执行评估项。
> 每项：检查什么 → 怎么检查 → 通过标准 → 证据要求。
> 智能体调用本文件，逐项收集证据并判定通过/不通过。

---

## 过门禁标准（7 项硬指标）

### 指标 1：实施真源文档已拆解（首个阶段）

- **检查什么**：`docs/f-实施真源文档-第N阶段.md` 是否落盘，大阶段→子阶段→步骤清晰
- **怎么检查**：读取文件，检查大阶段 / 子阶段 / 步骤 / 验收标准
- **通过标准**：首阶段已拆完、每步有验收标准、没一次性拆完所有阶段、临时想法写回真源文档
- **证据要求**：文件路径 + 章节结构

### 指标 2：前端能启动、首页能打开

- **检查什么**：前端项目能否启动，首页能否打开
- **怎么检查**：启动命令 + 浏览器 / 截图
- **通过标准**：能启动、首页能打开、路由能跑通
- **证据要求**：启动命令输出 + 首页截图 / URL

### 指标 3：数据库能连接、能建表、能插入查询

- **检查什么**：schema.sql 可执行 + 测试数据能插入查询
- **怎么检查**：执行 migration + 查询命令
- **通过标准**：库能连、表能建、能插入查询测试数据
- **证据要求**：schema.sql 路径 + 查询命令输出

### 指标 4：后端 4 条线跑通

- **检查什么**：启动线 / 接口线 / 业务线 / 运维线
- **怎么检查**：启动命令 + 健康检查 + 示例接口 + 日志
- **通过标准**：四条线都跑通
- **证据要求**：启动输出 + 健康检查响应 + 日志样本

### 指标 5：前后端联调验证通过

- **检查什么**：前端调通后端示例接口，跨域 / 响应格式 / 错误场景一致
- **怎么检查**：联调报告（请求命令 + 响应输出 + 是否通过）
- **通过标准**：联调报告完整，错误场景覆盖（参数错误 / 未登录 / 无权限 / 资源不存在 / 系统异常）
- **证据要求**：联调报告路径

### 指标 6：后端架构实施真源文档已落盘

- **检查什么**：`docs/k-后端架构实施真源文档.md` 是否生成
- **怎么检查**：读取文件，检查目录责任 / 接口规则 / 错误处理 / 启动证据 / 框架复用边界 / 新增模块规则
- **通过标准**：真源文档已落盘，写的是实际实现（非设计意图）；Agent 宪法已加引用条款
- **证据要求**：文件路径 + 章节标题；宪法引用位置

### 指标 7：已 Git 提交（至少 6 次）

- **检查什么**：Git 提交历史（真源文档拆解 / 前端骨架 / 数据库 / 后端骨架 / 联调 / 后端验收）
- **怎么检查**：`git log --oneline`
- **通过标准**：至少 6 次提交
- **证据要求**：`git log` 输出

## 自动验收流程

```
1. 智能体读取本文件的 7 项硬指标
2. 逐项检查（文件存在性 + 内容检查 + Git 历史）
3. 每项收集证据：
   - 文件路径
   - 关键内容行号
   - 命令输出（如 git log / 启动输出）
4. 生成验收报告：

   验收报告：架构门
   ================
   指标 1 实施真源文档：✅ 通过
     证据：docs/f-实施真源文档-第1阶段.md，大阶段/子阶段/步骤在第 3-40 行
   指标 2 前端启动：✅ 通过
     证据：npm run dev 输出，首页截图 index.png
   ...
   指标 7 Git 提交：❌ 未通过
     原因：只有 5 次提交，缺少"后端验收"提交
     整改建议：git commit -m "chore: 架构验收通过，固化实施真源文档"

5. 全部通过 → 推进状态到业务门
6. 有未通过 → 列出整改清单，不推进状态
```

## 常见遗漏项（反模式检查）

智能体验收时，额外检查以下反模式：

- ⚠️ 跳过实施真源文档拆解直接写代码
- ⚠️ 一次性拆完所有阶段（应该完成一个拆一个）
- ⚠️ 设计 token 没定就写页面
- ⚠️ 直接连数据库建表（必须先出 schema.sql）
- ⚠️ 金额用 float / 密码明文存储
- ⚠️ 后端骨架不基于架构设计文档
- ⚠️ 跳过后端联调直接写业务
- ⚠️ 4 条线没跑通就宣布完成
- ⚠️ 只验后端不验前端
- ⚠️ 前端只看代码不打开浏览器验证
- ⚠️ 验收不给证据，只说"已完成"
- ⚠️ 真源文档写设计意图不写实际实现
- ⚠️ 改了规则没同步真源文档

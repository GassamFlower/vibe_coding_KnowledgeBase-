# 深度手册引用说明

本目录不复制手册内容，而是引用知识库的 `../../docs/` 目录。

## 引用的 4 篇手册

| 手册文件 | 用途 |
|---|---|
| `../../docs/使用教程与导航手册.md` | 第一次用这套知识库时走一遍 |
| `../../docs/项目可视化流程手册.md` | 判断项目处于什么状态 |
| `../../docs/AI协作全流程操作手册.md` | 查某个阶段的详细操作细则（17 章） |
| `../../docs/全流程AI对话Prompt模板库.md` | 找可直接复制的 prompt |

## 为什么用引用而不是复制

1. **单一来源**：知识库 docs/ 是唯一来源，避免多处不同步
2. **自动继承**：知识库 docs/ 更新时，agent 自动继承
3. **精简可控**：agent 只在需要时引用对应章节，不污染上下文

## 未来计划

后续版本会在本目录创建精简版的"阶段手册摘录"：
- 从 docs/AI协作全流程操作手册.md 摘录每个阶段的核心步骤
- 从 docs/全流程AI对话Prompt模板库.md 摘录每个阶段的 prompt 模板
- 按阶段组织，智能体按需加载，避免一次性加载全部内容

## 移植时的处理

如果把 agent/ 移植到其他环境：
1. 把 `../../docs/` 的 4 个文件复制到本目录
2. 或者只复制需要的章节（按门禁组织）

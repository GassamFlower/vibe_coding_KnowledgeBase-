# 阶段1：从纯想法到立项

目标：把模糊念头变成可执行的立项依据。

动作清单：
- 用一句话说清「解决谁的什么问题」
- 写清楚「不解决什么」（范围边界）
- 列出 3 个必须成功的核心场景
- 列出至少 3 条真实用户证据的线索：访谈原话 / 真实行为 / 竞品数据，标来源
- 在 PROJECT_STATUS.md 标记 `state: 1`（纯想法），准备进入立项

提示：别急着写代码。想法阶段写代码 = 用实现代替思考，后期返工成本 10x。

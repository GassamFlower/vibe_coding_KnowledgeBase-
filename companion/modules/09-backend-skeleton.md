# 阶段9：后端骨架搭建（架构门）

目标：基于架构设计文档搭最小可运行后端骨架，跑通四条线。

动作清单：
- 复核语言 / 框架（不重新发散选型，只判断是否过度选型）
- 输出《后端架构实施计划》→ 写入 `docs/后端架构实施文档.md`
- 搭骨架：启动入口 / 环境变量 / 路由分组 / 健康检查 / 数据库连接 / 统一响应 / 统一错误 / 日志 / 参数校验 / 权限中间件占位
- 跑通四条线：启动线 / 接口线 / 业务线 / 运维线
- 提交 Git：`git commit -m "feat: 搭建后端最小可运行骨架，落盘后端架构实施文档"`

提示：不生成后端架构实施文档就搭骨架 = 前端有规矩后端没规矩。能用框架能力就别手写一套。

# 阶段7：前端骨架搭建（架构门）

目标：搭最小可运行前端骨架（能启动、首页能打开），不写业务页面。

动作清单：
- 确定设计风格（玻璃拟态 / Material / 企业级 / SaaS 极简 / AI 科技感）
- 定设计 token（颜色 / 字号 / 间距 / 圆角 / 阴影）并生效
- 接入 UI 组件库（不要到处手写按钮 / 弹窗 / 表格）
- 定目录 / 模块 / 组件边界规则
- 搭路由结构、封装接口层
- 写入前端架构实施文档，提交 Git：`git commit -m "feat: 搭建前端最小可运行骨架"`

提示：只搭壳不接数据。设计 token 没定就别写页面——否则满屏硬编码样式，后期改不动。

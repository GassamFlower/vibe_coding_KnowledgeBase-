# 阶段7：前端骨架搭建（架构门）

目标：搭最小可运行前端骨架（能启动、首页能打开），不写业务页面。

参考库：设计 token、组件与页面状态按 `skills/ui-design-system.md` 的「参考库（按需加载）」一节取用，该节对到本机 UIUX 参考库。

动作清单：
- 确定设计风格（一句话方向 + 2-3 个参考案例）
- 定设计 token（颜色 / 字号 / 间距 / 圆角 / 阴影 / 断点）并写明文件位置
- 接入 UI 组件库，写明版本、哪些直接用、哪些二次封装
- 定目录 / 模块 / 组件边界规则
- 搭路由结构、封装接口层
- 补齐页面状态示例：加载 / 空 / 错误 / 禁用 / 成功
- 定响应式断点和每个断点下的布局变化
- 定可访问性规则：键盘操作路径、对比度、语义标签
- 写 AI 规则：只允许使用 token，禁止直接写十六进制颜色和随手取的字号
- 写入前端架构实施文档，提交 Git：`git commit -m "feat: 搭建前端最小可运行骨架"`

提示：只搭壳不接数据。设计 token 没定就别写页面——否则满屏硬编码样式，后期改不动。

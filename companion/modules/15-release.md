# 阶段15：上线 + Skill 反哺（上线门 · 门禁校验）

目标：上线部署 + 观察 + 复盘 + 反哺知识库。

动作清单：
- 按顺序执行上线：生产构建 → 环境变量 → 数据库迁移 → 备份 → 发布 → 域名与证书 → 冒烟测试 → 日志与监控 → 告警测试 → 回滚演练 → 发布记录
- 生产冒烟：注册 / 登录 / 核心流程 / 支付或提交 / 查询结果，每步给请求和响应
- 记录部署证据：命令输出 / 线上访问验证 / 冒烟结果 / 回滚演练记录
- 记录上线后 24 小时 / 7 天 / 30 天指标，与基线对比；反馈逐条登记
- 建立 `docs/r-上线后30天迭代计划.md`：指标基线 / 反馈归类 / RICE 排序 / 本周假设 / 发布节奏与回退条件
- 整理踩坑清单（从 PROJECT_STATUS 踩坑记录提取）
- 反哺 `skills/`：哪条规则没覆盖 → 加；哪条不够明确 → 强化
- 反哺 Prompt 模板库
- 写 `docs/q-项目复盘报告.md`（上线记录 / 指标基线 / Keep / Change / Add / 踩坑清单 / 下次提醒），每条来源标注
- 更新 PROJECT_STATUS「下次项目提醒」
- 调用 `gate-上线门` 自动验收 → 知识库 git commit + push
- 提交 Git：`git commit -m "chore: 项目上线 + Skill 反哺"`

提示：上线完就结束不反哺 = 踩过的坑下次继续踩。复盘只写成绩不写问题 = 自欺。

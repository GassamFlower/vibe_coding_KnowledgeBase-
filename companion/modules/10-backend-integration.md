# 阶段10：后端联调（架构门）

目标：验证前后端骨架是否接得上。

动作清单：
- 前端调用后端示例接口（健康检查），返回正常
- 跨域配置正确
- 响应格式前后端一致
- 错误场景验证（参数错误 / 未登录 / 无权限 / 资源不存在 / 系统异常）
- 网络 / 超时场景验证
- 每项给：请求命令 + 响应输出 + 是否通过，提交 Git：`git commit -m "chore: 前后端骨架联调验证通过"`

提示：跳过后端联调直接写业务 = 接口接不上再查更难。只验证骨架联调，不写业务功能。

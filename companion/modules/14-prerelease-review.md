# 阶段14：上线前总验收（上线门）

目标：5 维度审查，无 🔴 严重项才上线。

动作清单：
- 回顾所有门禁是否已通过（立项 / 架构 / 业务）
- 功能清单逐项核对；模块清单状态明确（可上线 / 需优化 / 阻塞中）
- 文档完整性检查（立项 / 选型 / 架构设计 / 宪法 / 真源文档 / 验收报告齐全）
- 部署准备（环境变量 / 配置 / 数据库迁移 / 静态资源）
- 5 维度审查：结构 / 规则 / 安全 / 数据 / 可维护性，每项给 通过/风险/严重 + 证据
- 上线决策（go / no-go / conditional go），提交 Git：`git commit -m "chore: 上线前总验收通过"`

提示：没做总验收直接上线 = 线上出事没底。🔴 严重项没修完禁止上线。

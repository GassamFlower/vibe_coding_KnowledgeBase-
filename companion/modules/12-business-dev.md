# 阶段12：业务模块开发（业务门）

目标：一个模块一个模块交付，边写边接前端，做完一个验收 + 提交。

动作清单：
- 从实施真源文档取当前子阶段，明确本轮范围（锁死，不超范围）
- 后端写接口 → 立即接前端页面验证
- 模块测试：走 `testing-strategy` 六步法
- 模块验收：走 `verification-before-completion`，对照真源文档
- 每完成一个模块：git commit -m "feat: 完成XX模块"
- 完成后汇报三件事：哪些做完 / 改了哪些 / 怎么验证的 + 下一个子阶段

提示：一次写多个模块才验收 = 出问题分不清。临时想法写回真源文档，不直改代码。

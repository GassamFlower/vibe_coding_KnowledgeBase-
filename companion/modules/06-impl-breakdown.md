# 阶段6：实施真源文档拆解（架构门）

目标：把首个大阶段拆成「大阶段 → 子阶段 → 步骤 + 验收标准」的实施真源文档，作为后面所有阶段的执行依据。

动作清单：
- 取功能清单 + 阶段计划，确定本轮要做的首个大阶段
- 拆成：子阶段（每子阶段目标）→ 步骤（每步做什么）→ 每步验收标准
- 三大核心：明确执行目标、划定任务边界、制定验收标准
- 先只拆首个阶段，完成后再拆下一个（避免一次性太细导致后续大幅修改）
- 临时想法写回真源文档，不要直接改代码
- 写入 `docs/实施真源文档-第N阶段.md`，提交 Git：`git commit -m "chore: 完成首阶段实施真源文档拆解"`

提示：实施真源文档是后面所有阶段的"执行依据"。没有它，AI 自由发挥；没有验收标准，拆了等于没拆。

# 项目状态判断（随时评估）

开工前、每个阶段切换时，先判断项目处于 5 种状态之一：
1. 纯想法 — 只有模糊念头，无代码无文档
2. 烂尾 — 写过但中途放弃，结构残缺
3. 半成品 — 能跑但不完整，缺关键能力
4. 黑盒 — 能跑但无人懂原理，改不动
5. 健康 — 有文档、可维护、可演进

判断动作：
- 翻仓库：有代码吗？有 README / 文档吗？能本地跑起来吗？
- 问自己：换个人接手，他能懂并继续吗？
- 输出：在 PROJECT_STATUS.md 写 `state: <数字>` 与一句判定理由。

状态不是一成不变的——每次提交或阶段切换都重新判一次，写回 PROJECT_STATUS.md。

# 阶段4：架构设计

目标：确定目录、接口、错误、日志、数据库、权限、框架复用的规则。

交付物 `docs/e-架构设计文档.md`，7 项核心规则：
1. 目录结构规则（每个目录职责 / 放什么 / 不放什么）
2. 接口响应规则（统一格式 + 错误码表 + 分页规则）
3. 错误处理规则（异常捕获 / 日志记录 / 返回格式）
4. 日志规则（级别 / 格式 / 关键操作清单）
5. 数据库连接规则（连接池 / 事务边界 / ORM 使用规范）
6. 权限入口（认证中间件 / 角色校验 / 数据归属校验位置）
7. 框架复用边界（必须用框架 / 可封装 / 禁止自造）

提示：先画边界再写代码；边界错了，内部再优雅也白搭。AI 写代码前必须先对照架构设计确认对应位置。

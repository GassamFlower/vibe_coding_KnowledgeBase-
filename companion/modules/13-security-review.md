# 阶段13：后端安全审查（业务门 · 门禁校验）

目标：5 道关卡逐项查，重点查水平越权，交证据。

动作清单：
- 拆安全边界：身份认证 / 权限控制 / 输入校验 / 数据归属 / 注入防护
- 关键输入和普通输入分开处理；密码长度 + 组合 + 弱密码拦截 + 哈希 + 失败限制
- 输出系统权限设计表（每接口：是否登录 / 允许角色 / 是否只能操作自己数据 / 判断位置 / 无权限返回）
- 查注入：无字符串拼接用户输入（用 ORM / 参数化）
- 查过度防御 / 死代码
- 整改 + 回归 → 安全审查报告落盘 → 调用 `gate-业务门` 自动验收
- 提交 Git：`git commit -m "chore: 后端安全审查通过"`

提示：只做"要不要登录"忽略水平越权 = 最大坑。别让 AI 自己写过滤规则代替参数化查询。

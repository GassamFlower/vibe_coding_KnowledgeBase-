# 阶段8：数据库设计（架构门）

目标：先出数据库设计文件，再建表（禁止直接连库建表）。

动作清单：
- 从前端页面 + 立项业务对象清单反推数据（页面→字段、表单→提交、按钮→操作、状态→流转）
- 确认对象关系（一对一 / 一对多 / 多对多），画 ER 图
- 定数据库服务（MySQL/PostgreSQL + 是否 Redis）
- 表结构符合三大范式（金额 decimal、密码哈希、软删除字段一致）
- 先生成 schema.sql / migration，确认后再建表
- 数据库能连接、能建表、能插入查询测试数据，提交 Git：`git commit -m "feat: 完成数据库设计文件并跑通基础结构"`

提示：金额用 float 是坑；密码明文存储是事故。必须先出设计文件，禁止直连建表。
